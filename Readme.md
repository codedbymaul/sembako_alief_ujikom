# Sistem Informasi Toko Sembako

Sistem Informasi Toko Sembako adalah aplikasi berbasis web yang dibuat sebagai proyek Uji Kompetensi (UJIKOM) saat masih menempuh pendidikan di SMK.

Aplikasi ini dikembangkan untuk membantu pengelolaan data barang, data pengguna, transaksi penjualan, dan riwayat transaksi pada toko sembako.

Proyek ini menjadi salah satu pengalaman dalam mempelajari dan menerapkan pemrograman web, khususnya menggunakan PHP, MySQL, HTML, CSS, dan Bootstrap.

## Tujuan Proyek

Proyek ini dibuat sebagai bentuk penerapan ilmu yang telah dipelajari selama menempuh pendidikan di SMK, terutama dalam bidang pengembangan aplikasi berbasis web dan pengelolaan database.

Selain sebagai bagian dari Uji Kompetensi, proyek ini juga menjadi dokumentasi hasil belajar dan salah satu langkah awal dalam mengembangkan kemampuan di bidang pemrograman.

## Teknologi yang Digunakan

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP
